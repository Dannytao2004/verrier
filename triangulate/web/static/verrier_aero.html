01 · The idea01 · 灵感

Found with a pen.用一支笔找到的行星。

In 1846 nobody had seen Neptune — and Urbain Le Verrier didn't need to. Uranus was drifting off course, and the drift could mean only one thing: something unseen was pulling on it. He worked out where it had to be and mailed the coordinates to Berlin.1846 年，没人见过海王星，勒威耶也不需要见到它。天王星总在偏离轨道，而这种偏离只说明一件事：有一个看不见的东西在拉它。他算出了它该在哪儿，把坐标寄往柏林。

Johann Galle pointed a telescope there the night the letter arrived, and found a new planet within one degree.伽勒在收到信的当晚把望远镜对准那里——在不到 1° 的地方，发现了一颗新行星。

C-01 · HOW IT WORKS — K / Pexels

  1. 01

    Ask提问

    Name the number you need — next month's births, this quarter's deliveries, a figure no one reports.说出你要的数字：下个月的出生数、本季度的交付量、没人统计的数据。

  2. 02

    Approve确认

    Verrier drafts the estimation routes and sources. You sign off before a single search runs.Verrier 先拿出推算路线和数据来源，你批准之后才开始搜索。

  3. 03

    Gather搜集

    Parallel agents read the public record and bring back numbers with verbatim quotes.多个 agent 并行阅读公开记录，带回附原文引用的数字。

  4. 04

    Compute计算

    Code — not the model — runs the math: formulas, Monte Carlo, weights earned in backtests.计算交给代码而不是模型：公式、Monte Carlo、按回测表现加权。

  5. 05

    Deliver交付

    An estimate with a range, an evidence ledger and a dependency graph you can audit.带区间的估计，加上可审计的证据账本和依赖图。

D-01 · BUILT TO BE CHECKED — NASA

T-01

Sourced有出处

Every observed number carries a verbatim quote, checked against the page.每个观测数字都附原文引用，并与网页逐字核对。

T-02

Computed代码计算

The model plans; Python calculates. No mental math, ever.模型做规划，Python 做计算，从不「心算」。

T-03

Labelled假设透明

Assumptions are flagged, bounded and falsifiable — never hidden.假设会被标出、给出范围、可被证伪，绝不藏起来。

T-04

Audited独立核对

An independent check catches inputs that don't mean what the formula needs.独立核对，抓出「名不副实」的输入。

T-05

Leak-proof回测防泄漏

Backtests read only archived pages from before the cutoff.回测只读截止日之前的存档网页。

T-06

Fast when it can be该快就快

Already published? It finds it and stops — 37.7 s instead of 27 min.已经公布？找到就停——37.7 秒，而不是 27 分钟。
